Built on transparent logic

No fake ATS scores. No random career picks.

Every score in this application comes from a documented rule set you can inspect, and every career match follows one fixed formula. If the AI service is unavailable, the same features keep working with rule-based logic — and the interface tells you which engine produced the result.

  • ATS score = ten weighted category checks, adding to exactly 100 points
  • Career match = skills × 0.60 + interests × 0.40, with synonym-aware matching
  • Freshers are never forced to invent work experience
  • Uploaded originals are preserved; nothing is silently overwritten
